TFM: Arquitectura CNN y Preprocesado
Resumen Técnico: Arquitectura CNN y Preprocesado

1.  Preprocesado y Datos:

  - Estándar CHB-MIT: Uso de 18 canales SOTA.
  - Gestión de Duplicados: Limpieza de canales duplicados (ej. T8-P8-0).
  - Almacenamiento: Formato .pt para Lazy Loading.

2.  Arquitectura del Modelo (BaselineCNN):

  - Independencia de Canal: Uso de x.view(-1, 1, 256).
  - Entrada: in_channels=1.
  - Capas: Conv1 (16 filtros), Conv2 (32 filtros).
  - Capa Lineal: in_features=2048.
  - Clasificación: Media de probabilidades de canales.

3.  Consideraciones SOTA:

  - Kernel Size: Baseline usa 5, pero se recomienda probar kernels más grandes (64/128) para captar ondas de 3Hz.
