# Detección de Crisis Epilépticas con Modelos Híbridos y XAI

Proyecto de Fin de Máster en IA / Biomedicina. 
**Grupo:** Neuro-TFM-Squad

## 🧠 Objetivo
Desarrollar un modelo híbrido **CNN-Transformer** entrenado en el dataset **Bonn** y evaluado en **CHB-MIT**, incorporando técnicas de explicabilidad (**XAI**) para la localización del foco epiléptico.

## 🛠️ Stack Tecnológico
- **Lenguaje:** Python 3.x
- **Framework:** PyTorch
- **Entorno:** Conda / VS Code
- **Datasets:** Bonn University EEG & CHB-MIT Scalp EEG

## 📂 Estructura del Proyecto
- `data/`: Datasets y scripts de preprocesado (Ignorado por Git).
- `src/`: Código fuente (Modelos, Trainer, Utils).
- `notebooks/`: Experimentación y visualización.
- `experiments/`: Logs y resultados de cada ejecución.
